## 简体中文

界面支持 19 种语言，设置里可以不要托盘图标，更新检查默认先走 GitHub。

### 新增

- **隐藏系统托盘图标**：设置里勾上后通知区不再有图标。左键点任务栏读数照样开面板，右键照样弹菜单，入口不会丢。
- **新增 8 种界面语言**：印地语、印尼语、越南语、波兰语、荷兰语、土耳其语、孟加拉语、泰语。语言列表按字母序排列。
- **更新检查默认先走 GitHub**：GitHub 不通时自动换 Gitee；设置里仍可固定只用其中一个。

### 修复

- 切换到非中文界面后，「跟随系统」这个选项里仍混着中文。
- 部分语言（越南语、印地语、俄语、波兰语、荷兰语、土耳其语、孟加拉语、泰语）在设置窗口和列表面板里文字被截断。
- 磁盘面板「复制」出来的内容是英文。
- 中文系统下安装向导最后一页显示英文。
- 磁盘「类型」列在虚拟盘和存储空间上显示英文。
- 若干语言翻译错误：法语的「结束进程」、德语的网速单位、日语的虚拟内存路径、俄语的「重新吸附」等。

### 安装

下载 `PicoTray-1.3.0-setup.exe` 双击安装，会覆盖旧版本并保留设置。已装 1.2.x 的用户下次启动会收到更新提示。

## English

19 UI languages, an optional tray icon, and update checks that try GitHub first.

### New

- **Hide the tray icon**: the notification-area icon can be turned off in Settings. Left-clicking the taskbar readout still opens your panel and right-clicking still opens the menu, so nothing gets lost.
- **8 more UI languages**: Hindi, Indonesian, Vietnamese, Polish, Dutch, Turkish, Bengali and Thai. The language list is sorted alphabetically.
- **Update checks try GitHub first**: if GitHub is unreachable it falls back to Gitee. Settings can still pin a single source.

### Fixed

- The "follow system" entry still contained Chinese after switching to another language.
- Text was clipped in the settings window and list panels for Vietnamese, Hindi, Russian, Polish, Dutch, Turkish, Bengali and Thai.
- "Copy" in the disk panel produced English text.
- The installer's final page was English on Chinese systems.
- The disk "Type" column showed English for virtual disks and storage spaces.
- Various translation errors: French "kill process", the German speed unit, the Japanese virtual-memory path, Russian "re-attach", and others.

### Installation

Download `PicoTray-1.3.0-setup.exe` and run it; your settings are preserved. Existing 1.2.x
installs will be offered the update on next start.
