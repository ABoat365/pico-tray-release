## 简体中文

更新设置现在对安装包下载也生效了。

### 修复

- 在设置里选「只用 GitHub」时，安装包仍会先去 Gitee 试一次；现在严格按所选的源下载。
- 自动模式下安装包改为优先从 GitHub 下载，GitHub 不通再换 Gitee。

### 安装

下载 `PicoTray-1.3.1-setup.exe` 双击安装，会覆盖旧版本并保留设置。已装 1.3.0 的用户下次启动会收到更新提示。

---

## English

The update source setting now applies to the installer download as well.

### Fixed

- With "GitHub only" selected, the installer was still fetched from Gitee first; the chosen source is now respected.
- In auto mode the installer is downloaded from GitHub first, falling back to Gitee when GitHub is unreachable.

### Installation

Download `PicoTray-1.3.1-setup.exe` and run it; your settings are preserved. Existing 1.3.0
installs will be offered the update on next start.
