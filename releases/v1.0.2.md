## 简体中文

修复开机自启后读数整个跑到屏幕外面（Win11 任务栏托盘还没布局好时的一个空壳窗口导致的）。

### 修复

- 开机自启后不显示数据：读数窗口被摆到了屏幕左侧外面（实测 x=-233），一个像素都画不出来。
  根因是"贴托盘侧"的锚点取的是 `TrayNotifyWnd`，而 Win11 的任务栏托盘由 XAML 绘制，
  这个遗留窗口在 explorer 刚启动时是 0×0 的空框。现在会校验它的矩形，无效时改从屏幕
  像素上找托盘区左界。
- 目标位置兜底夹在任务栏范围内，任何情况下都不会再把窗口摆到屏幕外。

### 其他

- 诊断日志新增 `tray edge:` 行，可以直接看出托盘边界是从哪条路径来的（系统窗口 / 像素探测 / 估算）。

## English

Fixes the readout being placed entirely off-screen when started at boot (caused by an empty
placeholder window on Windows 11 when the taskbar tray has not been laid out yet).

### Fixes

- No data shown after auto-start at boot: the readout window was placed outside the left edge
  of the screen (measured x = -233), drawing nothing at all. The "tray side" anchor came from
  `TrayNotifyWnd`, but the Windows 11 tray is drawn by XAML and that legacy window is a 0×0
  empty frame right after explorer starts. Its rect is now validated, and when it is unusable
  the tray edge is located from screen pixels instead.
- The target position is clamped inside the taskbar, so the window can no longer end up
  off-screen under any circumstances.

### Other

- New `tray edge:` line in the diagnostic log, showing which path produced the tray boundary
  (system window / pixel probe / estimate).
