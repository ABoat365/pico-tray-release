## 简体中文

首个公开版本。

> 2026-11-17 修订：修复两处「任务栏数据被压在任务栏下面」的问题 —— 切换虚拟桌面、以及点「显示桌面」之后。
> 现在都会在 1~2 秒内自动抢回到最上层，不再需要点托盘图标才恢复。安装包已重新打包，版本号仍是 1.0.0。
> 已知限制：开始菜单打开期间任务栏会被资源管理器提到第三方窗口进不去的层级，那段时间数据会被盖住，关掉菜单即恢复。

### 任务栏监控

- 在通知区左侧显示：上传速度、下载速度、CPU 占用、内存占用
- **两行布局**（默认）：每列上下两项，横向占位约 170~190 px，可在设置里切回单行
- **网速只统计一块网卡**：默认自动选（已连接网卡里累计流量最大的那块），也可指定；右键「网卡」子菜单可切换
- 网速单位：自动（K/M/G）/ 固定 KB/s / 固定 MB/s，可选比特（b）或字节（B）
- 多显示器：可吸附到主显示器任务栏或第 N 个副屏；竖向任务栏自动改为纵向堆叠
- 只有文字、没有背景块，字直接浮在任务栏毛玻璃上；深浅色自动切黑字 / 白字
- 任务栏自动隐藏时一起隐藏，全屏应用时让位，资源管理器重启后自动恢复

### 屏幕亮度

- 每块显示器一条滑杆，拖动即时生效，标题带分辨率、重名自动加 #2/#3
- **笔记本内置屏也支持**：外接显示器走 DDC/CI，内置屏走 WMI
- 可勾选「同步调整所有显示器」；鼠标悬停在任务栏数据区上滚轮也能直接调

### 端口 → 进程

- 列出监听中的 TCP / 已绑定的 UDP 端口，以及对应的 PID 与进程名
- 按端口过滤；双击定位进程文件；可直接结束进程

### 其他

- **11 种界面语言**：简体中文 / 繁體中文 / English / 日本語 / 한국어 / Deutsch / Français / Español / Português / Русский / Italiano
- 设置项：网卡、网速单位、显示器、语言、更新源、两行显示、开机启动、显示项目
- **内置更新**：Gitee / GitHub 双源自动回退，下载后校验 SHA-256
- 单文件、无运行时依赖：exe 124 KB，私有内存 7 MB，空闲 CPU 约 0.4%

### 安装

下载 `PicoTray-1.0.0-setup.exe` 双击安装。默认装到 `%LocalAppData%\Programs\PicoTray`，**不需要管理员密码**；要给整台机器安装用 `setup.exe /ALLUSERS`。

本版本**没有代码签名**，首次运行 Windows SmartScreen 会提示，点「更多信息」→「仍要运行」即可。

### 系统要求

Windows 10 1809 及以上 / Windows 11，64 位。

### 已知限制

- 竖向任务栏受宽度限制，网速只能显示到 `12.3M` 这种精度，`/s` 会省略
- 只在主屏显示任务栏时，选副屏会退回主屏
- 显示器既不支持 DDC/CI、也不是 WMI 能管的内置屏时，亮度面板会显示"不支持亮度调节"
- 亮度面板首次打开可能要 1~2 秒（DDC 读取本身慢），之后是即时的
- 「结束进程」对管理员 / 系统进程会失败，需要以管理员身份运行本程序

## English

First public release.

> Revised 2026-11-17: fixed the taskbar readout disappearing behind the taskbar after switching virtual desktops (it used to need a tray-icon click to come back). The installer was rebuilt; the version stays 1.0.0.

### Taskbar monitor

- Shows upload speed, download speed, CPU usage and memory usage just left of the notification area
- **Two-row layout** by default (~170–190 px wide), switchable to a single row in Settings
- **Single adapter**: auto-selects the busiest connected adapter, or pin one; switchable from the tray submenu
- Speed units: auto (K/M/G) / fixed KB/s / fixed MB/s, in bits (b) or bytes (B)
- Multi-monitor: attach to the primary taskbar or the N-th secondary one; vertical taskbars switch to a stacked layout
- Text only — no background block, drawn straight on the taskbar's acrylic; black/white text follows the taskbar brightness
- Hides with auto-hide, yields to full-screen apps, recovers after Explorer restarts

### Brightness

- One slider per monitor, applied live; titles include the resolution, duplicates get #2/#3
- **Laptop internal panels supported**: external monitors via DDC/CI, internal panels via WMI
- Optional "adjust all monitors together"; the mouse wheel over the taskbar readout also works

### Port → process

- Lists listening TCP / bound UDP ports with their PID and process name
- Filter by port, double-click to reveal the executable, kill the process

### Other

- **11 UI languages**: Simplified Chinese / Traditional Chinese / English / 日本語 / 한국어 / Deutsch / Français / Español / Português / Русский / Italiano
- Settings: adapter, speed unit, display, language, update source, two-row layout, autostart, visible items
- **Built-in updater**: Gitee / GitHub mirrors with automatic fallback, SHA-256 verified downloads
- Single file, no runtime dependencies: 124 KB exe, 7 MB private memory, ~0.4% idle CPU

### Installation

Download `PicoTray-1.0.0-setup.exe` and run it. Installs per-user to `%LocalAppData%\Programs\PicoTray`
— **no admin password needed**. Use `setup.exe /ALLUSERS` to install for every user on the machine.

This build is **not code-signed**; SmartScreen will warn on first run — click **More info → Run anyway**.

### Requirements

Windows 10 1809 or later / Windows 11, 64-bit.

### Known limitations

- On vertical taskbars the width is limited, so speeds show as `12.3M` without `/s`
- With only one taskbar on the primary display, selecting a secondary monitor falls back to the primary
- Monitors that support neither DDC/CI nor WMI brightness report "brightness not supported"
- The brightness panel may take 1–2 s on first open (DDC reads are slow); afterwards it is instant
- "Kill process" fails for admin/system processes unless PicoTray runs elevated
