## 简体中文

新增「磁盘脱机 / 联机」面板，并修掉一批长时间运行才会暴露的问题。

### 新增

- **磁盘脱机 / 联机**：右键菜单 →「磁盘」，列出每块盘的类型（机械 / 固态）、接口、容量、盘符和当前状态，可以直接脱机、联机。需要管理员权限时会自己提权；系统盘不允许脱机，列表里会标出来。
- **左键单击可自选面板**：设置里可以选左键单击打开哪个面板（默认仍是亮度）。

### 修复

- **长时间运行后内存和句柄缓慢增长**：反复开关磁盘面板、改变窗口宽度、资源管理器重启，都会留下一些资源不释放。现在这几处都不再增长。
- **极少数情况下进程无声消失**：没有报错框、提示也没有，托盘图标直接不见，多发生在系统较忙或刚开机时。
- **网卡名或临时目录路径很长时，可能写坏内存**。
- **打开「磁盘」面板时窗口卡住十几秒**，脱机的机械盘还会被无谓唤醒。
- **「检查更新」可能永久失效**：后台线程失败过一次之后，就再也查不了更新。
- **亮度面板连续快速刷新时，可能停在旧读数上**。
- **版本号里数字过长时比较结果错乱**（会让更新判断出错），畸形内容还可能让解析出错。
- **IPv6 地址显示异常**。

### 安装

下载 `PicoTray-1.1.0-setup.exe` 双击安装，会覆盖旧版本并保留设置。已经装着 1.0.x 的用户下次启动会收到更新提示。

## English

Adds a disk offline / online panel, plus a batch of fixes for problems that only show up
after long uptime.

### New

- **Disk offline / online**: right-click menu → "Disks" lists every drive's type (HDD / SSD),
  bus, capacity, drive letters and current state, and lets you take a disk offline or bring it
  back online. Elevation is requested automatically; the system disk is marked and cannot be
  taken offline.
- **Left click opens the panel you choose**: pick which panel a left click opens (brightness
  by default).

### Fixes

- **Memory and handles creeping up over long uptime**: resources were left behind when closing
  the Disks panel, when the window was resized, and after an Explorer restart. None of them
  grows anymore.
- **The process occasionally disappearing with no error at all** — the tray icon is simply gone,
  usually while the system is busy or right after boot.
- **Possible memory corruption when the adapter name or the temp path is very long**.
- **The Disks panel freezing for up to ten seconds when opened**, and offline mechanical drives
  being woken up for nothing.
- **"Check for updates" could stop working permanently** after one failed background start.
- **Brightness panel sometimes stuck on stale readings** when refreshing rapidly.
- **Wrong version comparison when a version number contains very long digit runs** (which
  affects update decisions), and malformed content could break the parser.
- **IPv6 addresses displayed incorrectly**.

### Installation

Download `PicoTray-1.1.0-setup.exe` and run it; your settings are preserved. Existing 1.0.x
installs will be offered the update on next start.
